# BPD — Big Project Done

Фреймворк для ведения больших проектов в Claude Code.
Разбивает масштабную задачу на этапы, планирует, выполняет и проверяет.

## Команды

| Команда | Что делает |
|---------|-----------|
| `/bpd:start` | Начать новый проект (интервью → дорожная карта) |
| `/bpd:plan` | Спланировать следующий этап |
| `/bpd:plan N` | Спланировать конкретный этап |
| `/bpd:do` | Выполнить следующий этап |
| `/bpd:do N` | Выполнить конкретный этап |
| `/bpd:check` | Проверить результат этапа |
| `/bpd:status` | Показать прогресс проекта |
| `/bpd:update` | Изменить дорожную карту |
| `/bpd:help` | Эта справка |

## Быстрый старт

```
1. /bpd:start    ← расскажите о проекте
2. /bpd:plan     ← получите план первого этапа
3. /bpd:do       ← выполните этап
4. /bpd:check    ← проверьте результат
5. Повторяйте 2-4 для каждого этапа
```

## Масштабы проектов

| Масштаб | Этапов | Особенности |
|---------|--------|-------------|
| Быстрый | 1-5 | Простой цикл: план → выполнение |
| Средний | 5-15 | План → выполнение → проверка |
| Большой | 15+ | Полный цикл + субагенты (свежий контекст) |

## Рабочая папка

Все файлы проекта хранятся в `.bpd/`:
- `PROJECT.md` — описание проекта
- `ROADMAP.md` — дорожная карта (все этапы)
- `STATE.md` — текущее состояние
- `stages/` — папки этапов с планами и результатами

**Не удаляйте папку `.bpd/` — в ней вся память проекта!**

## Полезные советы

- Между этапами делайте `/clear` — свежий контекст работает лучше
- Можно пропускать проверку для быстрых проектов
- Дорожную карту можно менять в любой момент через `/bpd:update`
- Если нужно перепланировать этап — просто запустите `/bpd:plan N` заново
