<purpose>
Изменить дорожную карту: добавить, убрать, переставить, изменить этапы.
Автоматически пересчитывает нумерацию и обновляет STATE.md.
</purpose>

<process>

## 1. Проверка

Проверить существование `.bpd/`. Если нет — ошибка.

## 2. Показать текущую карту

Прочитать `.bpd/ROADMAP.md` и показать список этапов со статусами (аналогично `/bpd:status`).

## 3. Спросить что изменить

Используй AskUserQuestion:

```
questions: [
  {
    header: "Изменение",
    question: "Что вы хотите изменить?",
    multiSelect: false,
    options: [
      { label: "Добавить этап", description: "Вставить новый этап в карту" },
      { label: "Убрать этап", description: "Удалить этап из карты" },
      { label: "Изменить порядок", description: "Переставить этапы местами" },
      { label: "Изменить описание", description: "Поменять описание или цель этапа" },
      { label: "Разбить этап", description: "Разделить один этап на несколько" },
      { label: "Отмена", description: "Ничего не менять" }
    ]
  }
]
```

## 4. Выполнить изменение

### Добавить этап

1. Спросить: после какого этапа вставить? (или в конец)
2. Спросить: название и описание нового этапа
3. Добавить в ROADMAP.md
4. Создать папку `.bpd/stages/NN-название/`
5. Пересчитать нумерацию всех последующих этапов (переименовать папки)

### Убрать этап

1. Спросить: какой этап убрать?
2. Подтверждение: "Этап [N]: [Название] будет убран. Уверены?"
3. Пометить в ROADMAP.md как "Отменён" (НЕ удалять папку — там могут быть файлы)
4. Пересчитать нумерацию

### Изменить порядок

1. Спросить: какой этап переместить?
2. Спросить: куда? (после какого этапа)
3. Обновить ROADMAP.md
4. Переименовать папки (нумерация)

### Изменить описание

1. Спросить: какой этап?
2. Показать текущее описание и цель
3. Спросить что изменить
4. Обновить ROADMAP.md

### Разбить этап

1. Спросить: какой этап разбить?
2. Спросить: на сколько частей и как назвать
3. Обновить ROADMAP.md (один этап → несколько)
4. Создать новые папки
5. Пересчитать нумерацию

## 5. Обновить STATE.md

- Пересчитать "Этап N из M"
- Пересчитать прогресс
- Добавить в историю: "Дорожная карта обновлена: [что изменилось]"
- Обновить следующий шаг

## 6. Показать результат

Показать обновлённую дорожную карту (как в `/bpd:status`).

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 BPD ► КАРТА ОБНОВЛЕНА
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[Описание изменений]

[Обновлённая таблица этапов]
```

</process>

<important_rules>
- Никогда не удалять папки этапов — только помечать как отменённые
- Всегда подтверждать деструктивные действия (удаление, перемещение)
- Не трогать файлы внутри этапов (PLAN.md, RESULT.md) при пересчёте нумерации — только переименовывать папки
- Если у выполненного этапа меняется позиция — предупредить что это может повлиять на зависимости
</important_rules>

<success_criteria>
- [ ] Изменение выполнено
- [ ] ROADMAP.md обновлён
- [ ] Нумерация пересчитана
- [ ] Папки переименованы (если нужно)
- [ ] STATE.md обновлён
- [ ] Пользователь видит обновлённую карту
</success_criteria>
