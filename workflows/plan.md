<purpose>
Спланировать конкретный этап проекта. Создать PLAN.md с задачами, ожидаемым результатом и чеклистом качества.
</purpose>

<required_reading>
@./.claude/bpd/templates/PLAN.md
</required_reading>

<process>

## 1. Определить этап

**Если передан номер** ($ARGUMENTS): использовать его.

**Если номер не передан:** прочитать `.bpd/STATE.md`, найти текущий этап. Определить следующий неспланированный (нет PLAN.md в папке этапа).

**Если все этапы спланированы:** сообщить "Все этапы уже спланированы. Используйте `/bpd:do` для выполнения."

**Проверить:** Существует ли папка этапа в `.bpd/stages/`? Если нет — ошибка.

## 2. Прочитать контекст

Обязательно прочитать:
- `.bpd/PROJECT.md` — цель проекта, ограничения
- `.bpd/ROADMAP.md` — описание этапа, зависимости, критерии готовности
- `.bpd/STATE.md` — что уже сделано, принятые решения, проблемы
- `.bpd/config.json` — масштаб и режим

Для этапов после первого — также прочитать RESULT.md предыдущих этапов (если существуют), чтобы понимать контекст.

## 3. Уточняющие вопросы (для средних и больших проектов)

Если масштаб "средний" или "большой" — задай 1-2 вопроса по этапу:
- Есть ли особые пожелания к этому этапу?
- Есть ли приоритеты среди задач?
- Нужно ли что-то учесть из предыдущего опыта?

Для масштаба "быстрый" — пропустить этот шаг.

## 4. Создать PLAN.md

Создай файл `.bpd/stages/NN-название/PLAN.md` по шаблону.

**Задачи:** разбей этап на 3-10 конкретных задач. Каждая задача должна быть:
- Конкретной (не "поработать над текстом", а "написать введение к главе 3")
- Проверяемой (можно чётко сказать — сделано или нет)
- Атомарной (одно действие, не "написать и отредактировать")

**Чеклист качества:** 3-5 пунктов для проверки результата. Это будет использоваться в `/bpd:check`.

## 5. Показать план

Покажи план пользователю.

**В интерактивном режиме** — спроси подтверждение:
```
questions: [
  {
    header: "План этапа",
    question: "Вот план этапа. Всё верно?",
    multiSelect: false,
    options: [
      { label: "Да, начинаем", description: "План утверждён" },
      { label: "Нужны правки", description: "Хочу что-то изменить" }
    ]
  }
]
```

Если "Нужны правки" — спроси что изменить, обнови PLAN.md, покажи снова.

**В автоматическом режиме** — показать план и продолжить.

## 6. Обновить STATE.md

Обновить:
- Текущий этап и название
- Статус: "Спланирован"
- Последнее действие: дата + "Спланирован этап N"
- Следующий шаг: `/bpd:do`

## 7. Показать следующий шаг

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 BPD ► ЭТАП СПЛАНИРОВАН
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
