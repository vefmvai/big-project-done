<purpose>
Показать текущий прогресс проекта. Быстрая сводка без изменений.
</purpose>

<process>

## 1. Проверка

Проверить существование `.bpd/`. Если нет — сообщить: "В этой папке нет проекта BPD. Используйте `/bpd:start` чтобы создать."

## 2. Прочитать данные

- `.bpd/STATE.md`
- `.bpd/ROADMAP.md`
- `.bpd/config.json`

## 3. Посчитать статистику

Обойти `.bpd/stages/` и посчитать:
- Всего этапов (количество папок)
- Спланировано (есть PLAN.md)
- Выполнено (есть RESULT.md)
- Проверено (есть CHECK.md)
- На доработке (статус "Доработка" в STATE.md)

Процент прогресса = проверенные / всего * 100

## 4. Показать сводку

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 BPD ► СТАТУС ПРОЕКТА
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Проект: [Название]
Масштаб: [быстрый/средний/большой]
Режим: [интерактивный/автоматический]

Прогресс: [████████░░] 80% ([X] из [Y] этапов)

## Этапы

| # | Этап | Статус |
|---|------|--------|
| 01 | [Название] | ✓ Проверен |
| 02 | [Название] | ✓ Проверен |
| 03 | [Название] | ● Выполнен |
| 04 | [Название] | ◎ Спланирован |
| 05 | [Название] | ○ Не начат |

## Сейчас

Этап [N]: [Название]
Статус: [текущий статус]

## Следующий шаг

[/bpd:plan | /bpd:do | /bpd:check — в зависимости от статуса]
```

**Обозначения статусов:**
- ✓ — Проверен (завершён)
- ● — Выполнен (ждёт проверки)
- ◎ — Спланирован (готов к выполнению)
- ◐ — В работе
- ⚠ — На доработке
- ○ — Не начат

</process>

<success_criteria>
- [ ] Прогресс посчитан правильно
- [ ] Все этапы отображены со статусами
- [ ] Следующий шаг понятен
</success_criteria>
