# Как работать с BPD — инструкция для пользователя

## Что это такое

BPD (Big Project Done) — это система для ведения больших проектов с помощью Claude Code. Она помогает разбить сложную задачу на понятные шаги и не потерять контекст даже если работа растянулась на несколько дней или недель.

Примеры проектов, для которых подходит BPD:
- Написание книги или курса
- Подготовка большого исследования
- Создание сайта или приложения
- Организация мероприятия
- Любой проект, который нельзя сделать за один присест

## Как установить

BPD устанавливается **один раз** — после этого команды `/bpd:*` доступны в любом проекте.

Напишите в чат Claude Code:

```
Установи фреймворк BPD из репозитория github.com/vefmvai/big-project-done
```

Claude скачает фреймворк и установит его глобально. Рабочие файлы проекта (`.bpd/`) создаются автоматически при запуске `/bpd:start`.

## Как пользоваться

### Шаг 1. Запустить проект

Напишите в чат:
```
/bpd:start
```

Claude спросит:
- Что за проект?
- Какая цель?
- Что входит, а что не входит в проект?

Затем предложит разбивку на этапы. Вы можете поправить — добавить, убрать, переименовать этапы.

В конце Claude создаст папку `.bpd/` с описанием проекта и дорожной картой.

### Шаг 2. Спланировать этап

```
/bpd:plan
```

Claude возьмёт следующий этап из дорожной карты и разобьёт его на конкретные задачи. Например, если этап — "Написать введение к курсу", задачи могут быть:
- Определить целевую аудиторию
- Написать приветственный текст
- Описать что ученик получит
- Составить список необходимого

Вы можете поправить план перед запуском.

### Шаг 3. Выполнить этап

```
/bpd:do
```

Claude выполнит задачи по плану. Для больших проектов он запустит отдельного агента — тот получит свежий контекст и не будет путаться в накопившейся истории чата.

### Шаг 4. Проверить результат

```
/bpd:check
```

Claude проверит: все ли задачи выполнены, все ли файлы на месте, соответствует ли результат критериям качества. Если что-то не так — скажет что доработать.

### Повторить

Вернитесь к шагу 2 для следующего этапа:
```
/bpd:plan → /bpd:do → /bpd:check
```

И так пока проект не будет готов.

## Полезные команды

| Команда | Когда использовать |
|---------|-------------------|
| `/bpd:status` | Посмотреть прогресс — сколько этапов сделано, сколько осталось |
| `/bpd:update` | Изменить план — добавить новый этап, убрать ненужный, поменять порядок |
| `/bpd:help` | Показать справку по всем командам |

## Советы

### Между этапами делайте /clear

После каждого этапа напишите `/clear` — это очистит историю чата. Claude не потеряет прогресс проекта (всё хранится в файлах), но получит свежий контекст и будет работать качественнее.

### Можно менять план в любой момент

Поняли что нужен дополнительный этап? Или хотите убрать ненужный? Просто скажите:
```
/bpd:update
```
Claude покажет текущую дорожную карту и спросит что изменить.

### Масштаб проекта

При старте Claude спросит о масштабе:

- **Быстрый** (1-5 этапов) — для небольших задач. Claude делает всё сам в текущем чате
- **Средний** (5-15 этапов) — стандартный режим. План → выполнение → проверка
- **Большой** (15+ этапов) — для серьёзных проектов. Claude запускает отдельных агентов для планирования, выполнения и проверки, чтобы каждый работал со свежим контекстом

### Не удаляйте папку .bpd

В ней хранится вся память проекта — описание, планы, результаты, состояние. Если её удалить — Claude забудет всё о проекте.

### Можно вернуться к проекту через день или неделю

Просто напишите `/bpd:status` — Claude прочитает файлы проекта и покажет где вы остановились. Дальше продолжайте с `/bpd:plan` или `/bpd:do`.

## Частые вопросы

**Можно ли использовать BPD для нескольких проектов одновременно?**
Да, но каждый проект должен быть в своей папке. BPD хранит всё в папке `.bpd/` внутри проекта.

**Что если Claude сделал этап плохо?**
Команда `/bpd:check` покажет проблемы. Скажите Claude что исправить — он переделает. Или запустите `/bpd:do` заново для этого этапа.

**Можно ли пропустить этап?**
Да. Скажите `/bpd:plan 5` чтобы спланировать конкретный этап по номеру, минуя предыдущие.

**Можно ли работать без проверки?**
Да, для быстрых проектов можно пропускать `/bpd:check` и сразу переходить к следующему `/bpd:plan`.
